### Cardinality policy

Bounded labels only: `operation`, `result`, `phase`, `transport`, `shard`, `worker`, `owner`, `replica`, `node`, `reason`.  
**Never:** account_id, order_id, trade_id, event_id, request_id.

### Troubleshooting

| Symptom | Start here |
|---------|------------|
| Target DOWN | container `docker compose ps`, `/health` |
| Node not ready | `/ready`, data volume permissions |
| No WAL metrics | process path that calls WAL (idle process shows 0) |
| No consensus metrics | gauges only set when consensus.Node runs |
| High P99 | Trading Performance phases + WAL dashboard |
| MD gaps | Market Data recovery failures |

## Notes

- Idle nodes show zeros for counters — expected until traffic (P10.3).
- Engine phase histograms are **nested**, not additive to command latency (P7.2).
- Consensus is_leader/term appear when consensus instrumentation is active.
