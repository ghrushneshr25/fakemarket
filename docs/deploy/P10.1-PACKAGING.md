## Topology

```
fake-market-node-a  :8081 → 8080
fake-market-node-b  :8082 → 8080
fake-market-node-c  :8083 → 8080
prometheus          :9090
grafana             :3000  (admin/admin local only)
```

Each node has a **separate named volume** for `/data` (WAL + consensus metadata).

## Commands

```bash
docker compose build
docker compose up -d
curl -s localhost:8081/health
curl -s localhost:8081/ready
curl -s localhost:8081/metrics | head
docker compose logs -f node-a
docker compose down          # volumes retained
docker compose down -v       # wipe data (destructive)
```

## Environment (per node)

| Variable | Purpose |
|----------|---------|

| `FAKEMARKET_DATA_DIR` | `/data` |
| `FAKEMARKET_WAL_DIR` | `/data/wal` |
| `FAKEMARKET_CONSENSUS_DIR` | `/data/consensus` |
| `FAKEMARKET_HTTP_PORT` | `8080` |
| `FAKEMARKET_ENV` | `production` |

## Health / Ready

| Endpoint | Meaning |
|----------|---------|
| `GET /health` | Liveness — process up |
| `GET /ready` | Readiness — data dirs writable, listener up (503 until ready) |
| `GET /metrics` | Prometheus exposition |

**No financial commands accepted before Ready** (ready flipped only after data-dir probe + listen).

## Image

- Multi-stage build (`golang:1.25-alpine` → `alpine:3.20`)
- Non-root user `fakemarket`
- No secrets in image
- `VOLUME /data`

## Persistence

```
docker compose down
docker compose up -d
```

Named volumes `node-*-data` retain `/data/wal` and `/data/consensus`.

## SIGTERM

`main` traps SIGTERM → 10s graceful HTTP shutdown → ready=false.
