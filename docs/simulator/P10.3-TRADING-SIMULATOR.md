# P10.3 — Trading Simulator

## Status

**IMPLEMENTED** (CTO review pending)

## Purpose

Production-style **demonstration workload** that drives the **real** exchange path so
P10.2 dashboards show live activity.

| | P7 | P10.3 |
|--|----|-------|
| Owner | Formal benchmarks | Demo / operator traffic |
| Path | Controlled benches | gRPC → Service → match → WAL |
| Claims | Throughput/latency science | Observed demo rates only |

## Architecture

```
fakemarket-sim
    → gRPC TradingService (bufconn in-process)
    → grpcapi.TradingServer
    → trading.Service
    → AuthorityGate (if set) / Router / Workers
    → Risk / Matching
    → Financial WAL
    → metrics (existing instrumentation)
```

**Forbidden:** direct book/WAL/trade/metric mutation.

## CLI

```bash
go run ./cmd/fakemarket-sim \
  -seed 42 \
  -scenario normal \
  -commands 800 \
  -rate 400 \
  -clients 4 \
  -instruments 8 \
  -accounts 50

# or
make sim
```

### Flags

| Flag | Default | Meaning |
|------|---------|---------|
| `-seed` | 42 | Deterministic RNG |
| `-scenario` | normal | quiet \| normal \| active \| replay |
| `-duration` | 2m | Used if `-commands` = 0 |
| `-commands` | 0 | Hard stop after N cmds |
| `-rate` | 50 | Target cmds/sec (paced) |
| `-clients` | 4 | Concurrent gRPC workers |
| `-instruments` | 8 | SIM-* universe |
| `-accounts` | 50 | SIM-ACCOUNT-NNNN |
| `-wal` | temp | WAL directory |

## Determinism

- xorshift64* RNG from seed  
- `GenerateStream` builds full command list up front  
- `Fingerprint` = FNV-64a over config + stream (no wall-clock/UUID)  
- Same seed+config → same fingerprint (tested)

## Order mix

- Limit passive / aggressive (crossing)  
- Market  
- Cancel of **simulator-owned** live orders only  

Sellers = second half of accounts (pre-loaded inventory).

## Canonical demo

```text
Seed: 42
Scenario: normal
Commands: 800
Rate: 400/s
```

Expect: accepted > 0, trades > 0, WAL sequence > 0, fingerprint stable.

## Graceful stop

SIGINT/SIGTERM stops generating new jobs, drains workers, prints summary.

## Docs note

P10.4 owns failure injection demos. P10.3 only generates healthy traffic.
